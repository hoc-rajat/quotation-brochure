## Document refinements

The quotation separates sample acceptance charges from membership billing after successful registration and the overall first-year commitment. VAT remains illustrative; this is not an issue-ready quotation. Section letters and visible version labels are removed. Three-service quotations use four pages so service and membership scope remain readable; other quotations use three. The public Registry brochure uses three pages and contains no lead details or unrelated registration price list.

Both download buttons retain the existing browser print / Save as PDF workflow. Export waits for fonts, images and the selected document to render. Choose Save as PDF in the browser dialog; no server-side PDF service or checkout has been added.

### Verification

Run `npm run build`, `npx tsc --noEmit`, and `npm run lint`.

With the development server at `http://127.0.0.1:5173`, run `node scripts/verify-documents.mjs` in an environment with Playwright available. Set `PLAYWRIGHT_MODULE` to its module entry if it is installed outside this project, and `CHROME_PATH` for a non-default Chrome executable. The script checks all 11 valid service combinations with all three membership choices, screen/print footer boundaries, mobile fitting, brochure privacy and both buttons' selected print content. It generates sample PDFs in `output/pdf` and intermediate stress-case PDFs in `tmp/pdfs`. The native Save as PDF dialog itself is not automated.
